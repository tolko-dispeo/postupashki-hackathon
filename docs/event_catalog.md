# Каталог событий

Статус: ожидает результата отдельной задачи команды.

Для каждого события нужно определить:

- `event_name`;
- момент возникновения;
- обязательные идентификаторы;
- дополнительные параметры;
- источник данных;
- правила дедупликации;
- допустимость анонимного события;
- пример JSON.

Минимальные кандидаты: `ad_click`, `landing_view`, `course_view`, `manager_click`, `conversation_started`, `order_created`, `payment_succeeded`.
