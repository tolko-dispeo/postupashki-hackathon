# Логическая модель

Статус: следующий этап после утверждения концептуальной модели.

Здесь для каждой таблицы будут зафиксированы:

- первичный ключ;
- внешние ключи;
- обязательные и необязательные поля;
- типы данных;
- уникальные ограничения и индексы;
- правила удаления и обновления;
- поля `created_at`, `source_system`, `is_synthetic`;
- политика хранения и хеширования идентификаторов.

До утверждения этого документа ORM-модели и первая SQL-миграция намеренно не создаются.
