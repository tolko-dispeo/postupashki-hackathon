# Расширенный локальный synthetic-набор

Набор предназначен только для локальной демонстрации дашборда. Он не заменяет
контрольные fixtures Contract v1 и не должен загружаться в производственную БД.

Состав:

- 10 кампаний;
- 20 Telegram-размещений;
- 7 180 обычных рекламных кликов;
- 50 дополнительных multi-touch-путей;
- полный путь `ad_click → landing_view → course_selected → manager_click → lead_created → order_created → payment_succeeded`;
- разные расходы, чеки и конверсии, чтобы на графиках были прибыльные и убыточные кампании.

Ожидаемый итог с настройками по умолчанию:

- 10 кампаний и 20 размещений;
- 7 280 кликов, включая multi-touch;
- 7 230 уникальных посетителей;
- 772 лида, 456 заказов и 273 оплаты;
- выручка 4 178 650 ₽, расходы 2 265 000 ₽, ROMI 84,49%;
- качество данных: `ok`, ошибок и предупреждений нет.

## Установка файлов

Скопируйте папки `scripts` и `data` из этого набора в корень проекта. Они добавят
новые файлы и не заменят существующий `scripts/seed_demo.py`.

В комплект также входит уже подготовленная база
`data/postupashki_mvp_large_demo.sqlite3`. Для её просмотра повторно запускать
генератор необязательно.

## Запуск в PowerShell

Из корня проекта:

```powershell
$env:DATABASE_URL = "sqlite:///data/postupashki_mvp_large_demo.sqlite3"
python scripts/seed_large_demo.py
pytest
streamlit run src/postupashki_mvp/dashboard/app.py
```

Генератор сам создаёт таблицы и перед заполнением полностью очищает именно эту
демонстрационную БД. Повторный запуск создаёт тот же объём данных заново.

Для API в отдельном терминале с тем же `DATABASE_URL`:

```powershell
uvicorn postupashki_mvp.api:app --reload
```

Чтобы вернуться к прежнему небольшому набору, достаточно снова установить:

```powershell
$env:DATABASE_URL = "sqlite:///data/postupashki_mvp_v2.sqlite3"
```

Защитная проверка не разрешит очистить SQLite-файл без `large_demo` или
`synthetic` в названии. Флаг `--force` существует для осознанного обхода этой
проверки, но для демонстрации он не нужен.
