# Synthetic daily revenue

`daily_revenue.csv` - детерминированный пример, не реальные продажи Поступашек.
56 дней с 2026-07-01, единица выручки условная.

Для дня с индексом i (начиная с 0) и weekday (понедельник = 0):

```
10000 + [0, 2000, 4000, 1000, 8000, 15000, 12000][weekday]
      + 75 * i + ((17 * i) % 7 - 3) * 400
```

Назначение: воспроизводимая демонстрация forecast/backtest без персональных
данных. Запуск и ограничения описаны в `docs/forecast_backtest.md`.
