# Расширения после MVP

Сюда добавляются независимые пакеты:

- `telegram_collector/` — сбор и синхронизация постов;
- `post_classifier/` — NLP-классификация контента;
- `incrementality/` — эксперименты и causal inference;
- `forecasting/` — прогнозирование продаж;
- `budget_optimizer/` — рекомендации по распределению бюджета.

Расширения читают стабильные данные ядра или добавляют собственные таблицы через миграции. Они не должны менять смысл уже записанных событий.
